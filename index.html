1. Animated System Pipeline — How It Works

Each incoming Meta lead is processed through 6 sequential algorithmic stages in real time. Hover over any stage to expand details.

IN
🔌 Incoming Lead Data — Meta Ads / Webhook INPUT
Raw form submission arrives via Meta Lead Ads Webhook or manual entry. Contains: name, email, phone, lead source, ad placement, total visits, time on website, last activity, occupation.
1
🔬 Stage 1: Feature Pruning & Shapley Attribution GAME THEORY
100+ noisy one-hot encoded columns are screened using Variance Thresholding, Pearson Correlation, and Shapley Value attribution. Reduces to 42 high-signal predictors.
φ_j = Σ [ |S|!(|F|-|S|-1)! / |F|! ] × (f(S∪{j}) − f(S))
2
🤖 Stage 2: XGBoost Conversion Scoring ML MODEL
The 42-feature vector is passed through a trained XGBoost Gradient Boosted Tree classifier using 2nd-order Taylor expansion of log-loss. Outputs a raw base probability P_base ∈ [0,1] and a base score 0–100.
w_j* = −(Σ g_i) / (Σ h_i + λ) | g_i = p̂_i − y_i | h_i = p̂_i(1−p̂_i)
3
📐 Stage 3: Platt Calibration CALIBRATION
Raw XGBoost probabilities are overconfident. A logistic sigmoid transform (Platt Scaling) is fitted on the validation set to align predicted probabilities with real-world conversion frequencies.
P_cal = 1 / (1 + exp(A × P_base + B))
4
⏱️ Stage 4: Exponential Time-Decay Engine DECAY LAW
Score decays continuously while the lead remains uncontacted. The half-life is set to 24 hours. A lead uncontacted for 24h loses 50% of its score. After contacting, decay is frozen.
S(t) = S₀ × e^(−λ×Δt) | λ = ln(2)/24 ≈ 0.0289 hr⁻¹
5
📊 Stage 5: Wald Confidence Intervals STATISTICS
For each lead, a 95% binomial confidence margin is computed. Wide margins → Uncertain; Narrow margins → High Confidence. Sales reps see the score range [lower, upper] on the dashboard.
Margin = 1.96 × √(p(1−p) / n) | n = 30 + TotalVisits
6
🏆 Stage 6: Priority Queue Construction OPTIMIZATION
All leads are sorted in a strict lexicographic order: first by decayed score (highest first), then by CPC (lowest first). This maximizes revenue while minimizing Meta ad spend.
Sort: [decayed_score DESC, cpc ASC] → Hot / Warm / Cold
✓
📤 Output → React Dashboard + SQLite Database OUTPUT
The fully scored lead — with status, calibrated probability, confidence bounds, and decayed score — is written to the SQLite database and displayed live on the React priority queue dashboard.

5. Mathematical Formulations

5.1 Shapley Feature Attribution

Theorem — Lloyd Shapley (1953), Nobel Prize in Economics 2012

The only attribution function satisfying Efficiency, Symmetry, Null Player, and Additivity axioms:

\[ \phi_j = \sum_{S \subseteq F \setminus \{j\}} \frac{|S|!\,(|F| - |S| - 1)!}{|F|!} \Big( f(S \cup \{j\}) - f(S) \Big) \]

F = all features • S = a coalition (subset) of features • f(S) = model output using only features in S • φ_j = fair credit attributed to feature j

💡 Plain-English Intuition
Imagine 5 co-workers completing a project. Shapley values test every possible team combination to fairly assign each person's contribution to the final result — regardless of order or correlation with others.

5.2 XGBoost Second-Order Gradient Boosting

Algorithm — Chen & Guestrin (2016), KDD Best Paper Award

Optimal leaf weight minimizing the regularized second-order Taylor approximation of log-loss:

\[ w_j^* = -\frac{\displaystyle\sum_{i \in I_j} g_i}{\displaystyle\sum_{i \in I_j} h_i + \lambda} \qquad g_i = \hat{p}_i - y_i \qquad h_i = \hat{p}_i(1 - \hat{p}_i) \]

g_i = first derivative (gradient — how wrong the prediction is) • h_i = second derivative (Hessian — how fast the error is changing) • λ = L2 regularization penalty to prevent overfitting

💡 Plain-English Intuition
Standard machine learning only checks if the prediction went up or down (first derivative). XGBoost also checks the curvature of the error (second derivative), like knowing not just that a car is moving, but how fast it's accelerating — giving more precise corrections.

5.3 Platt Scaling Calibration

Method — Platt (1999), Probabilistic Outputs for SVMs
\[ P_{\text{cal}}(Y=1 \mid f(\mathbf{x})) = \frac{1}{1 + \exp\!\Big(A \cdot f(\mathbf{x}) + B\Big)} \]

A, B = scalar parameters fitted via Maximum Likelihood Estimation on the validation partition • f(x) = raw XGBoost score • Output is a genuine probability ∈ (0,1) aligned with real conversion rates

💡 Plain-English Intuition
A weather app saying "90% chance of rain" must be correct 90 times out of 100. Platt scaling recalibrates AI scores so they behave like true probabilities — not just rankings — allowing reliable business forecasting.

5.4 Exponential Time-Decay Law

Differential Equation — Analogous to Radioactive Half-Life & Newton's Law of Cooling
\[ \frac{dS}{dt} = -\lambda S(t) \implies S(t) = S_0 \cdot e^{-\lambda \Delta t} \qquad \lambda = \frac{\ln 2}{t_{1/2}} = \frac{0.6931}{24} \approx 0.0289\;\text{hr}^{-1} \]

S₀ = base score at submission • Δt = elapsed uncontacted hours • λ = decay constant • t½ = 24h: score halves every 24 hours uncontacted

💡 Plain-English Intuition
Like radioactive material losing half its atoms every fixed period, a lead loses half its urgency every 24 hours. A Hot lead that was 95 this morning will be only ~67 by tomorrow morning if not contacted.

5.5 Wald 95% Confidence Interval

Theorem — Central Limit Theorem & De Moivre–Laplace Normal Approximation
\[ \hat{p} \pm z_{\alpha/2} \cdot \sqrt{\frac{\hat{p}(1-\hat{p})}{n}} = \hat{p} \pm 1.96 \cdot \sqrt{\frac{\hat{p}(1-\hat{p})}{n}} \qquad n = 30 + \text{TotalVisits} \]

ẑα/2 = 1.96 = z-score for 95% confidence (from standard normal table) • n = effective sample depth • Wider intervals → less certainty → Uncertain tier

💡 Plain-English Intuition
A poll predicting election results always states a margin of error (e.g. "58% ± 3%"). Our system applies the same mathematics to each individual lead: "This person has a 92% conversion probability, ± 4%, with High Confidence."

5.6 Lexicographic Priority Queue

Multi-Attribute Utility Theory — Strict Lexicographic Ordering
\[ \text{Lead}_A \succ \text{Lead}_B \iff \Big(S_A(t) > S_B(t)\Big) \;\lor\; \Big(S_A(t) = S_B(t) \;\land\; \text{CPC}_A < \text{CPC}_B\Big) \]

S(t) = time-decayed lead score (primary key) • CPC = Cost Per Click from Meta Ads (tie-breaker key) • Lower CPC with equal scores = better ROI per contact

💡 Plain-English Intuition
Like a hospital triage system: the most critical patients are seen first (highest score), and if two patients have equal severity, the one who arrived via the cheaper ambulance route gets priority — optimizing both care quality and operational cost.

6. Glossary of All Terms Used

Every technical term used in MetaLeadIQ, explained for non-specialists:

ROC-AUC Metric
Receiver Operating Characteristic — Area Under the Curve. Measures how well the model separates buyers from non-buyers. 0.5 = random guessing, 1.0 = perfect. Our model: 0.9178.
Shapley Values Game Theory
A method from cooperative game theory that fairly distributes the prediction credit to each input feature based on its average marginal contribution across all possible combinations.
XGBoost ML Model
Extreme Gradient Boosting. An ensemble of decision trees built sequentially, each correcting the errors of the previous tree using first-order gradients AND second-order Hessians for optimal convergence.
Platt Scaling Calibration
A post-processing method that fits a logistic (sigmoid) function on validation set outputs to transform raw classifier scores into properly calibrated probabilities.
Decay Constant (λ) Physics
Controls the rate at which the lead score diminishes. Derived as λ = ln(2)/t½. With t½ = 24h, λ ≈ 0.0289 hr⁻¹, meaning the score drops by ~2.86% per hour continuously.
Half-Life (t½) Physics
The time required for the lead score to decay to exactly 50% of its original value. Set to 24 hours based on empirical sales research showing dramatic conversion drop-off after 1 day uncontacted.
Confidence Interval Stats
A range of values around the point estimate within which the true probability lies with 95% statistical certainty. Example: "92% ± 4%" means the true conversion probability is between 88% and 96%.
CPC Marketing
Cost Per Click. The amount paid to Meta (Facebook/Instagram) for each click on your advertisement. Lower CPC = more cost-efficient customer acquisition. Used as a secondary priority key.
CTR Marketing
Click-Through Rate. The percentage of people who saw an ad and clicked on it. Higher CTR = more compelling ad creative. Formula: Clicks / Impressions × 100%.
ROAS Marketing
Return on Ad Spend. Revenue generated per dollar spent on Meta advertising. MetaLeadIQ's priority queue is optimized to maximize ROAS by contacting high-score, low-CPC leads first.
Precision Metric
Of all leads the model labels as likely converters, what fraction actually convert? Formula: TP / (TP + FP). Our model: 80.71%. In the top decile: 95.68%.
Recall Metric
Of all leads that will genuinely convert, what fraction does the model correctly identify? Formula: TP / (TP + FN). Our model: 79.92%. Captures 4 out of 5 real buyers.
F1-Score Metric
The harmonic mean of Precision and Recall, balancing both in one metric. Formula: 2 × (Precision × Recall) / (Precision + Recall). Our model: 0.8031.
Gradient Calculus
The first derivative of the loss function with respect to predictions. Tells the model which direction to adjust predictions to reduce error. In XGBoost: g_i = p̂_i − y_i.
Hessian Calculus
The second derivative of the loss function. Tells the model how quickly the error is changing, enabling more precise step sizes. In XGBoost: h_i = p̂_i(1 − p̂_i).
MLE Statistics
Maximum Likelihood Estimation. A method of estimating model parameters by finding the values that make the observed data most probable. Used to fit Platt Scaling parameters A and B.
CLT Statistics
Central Limit Theorem. States that the sampling distribution of any mean approaches a normal distribution as sample size grows, regardless of the original distribution. Foundation for Wald confidence intervals.
Webhook Engineering
An HTTP POST request automatically sent by Meta's servers to our FastAPI endpoint the moment a user submits a Lead Form on Facebook or Instagram. Triggers real-time ML scoring instantly.
FastAPI Engineering
A modern Python web framework for building high-performance REST APIs. Powers the MetaLeadIQ production server at port 8000. Handles webhook ingestion, ML inference, database writes, and dashboard queries.
WAL Mode (SQLite) Database
Write-Ahead Logging. A SQLite journal mode that allows multiple concurrent reads while a write is in progress — essential for the dashboard (reading) and webhook (writing) operating simultaneously without locks.
One-Hot Encoding ML
Converting a categorical variable (e.g., "Lead Source = Google") into binary indicator columns (e.g., Lead_Source_Google = 1, Lead_Source_Facebook = 0). Required by tree-based ML models.
Top-Decile Precision Metric
Precision computed only on the highest-scoring 10% of leads (the top decile). This is the most business-relevant metric: of the top 10% of leads that the system flags as Hot, 95.68% actually convert.
Lexicographic Order Math
Like dictionary ordering: compare first by the primary key (score); only compare by the secondary key (CPC) when the primary key is equal. This ensures clear, unambiguous priority ranking with no ties left unresolved.
Regularization (λ) ML
A penalty term added to the loss function to discourage overly complex trees. Prevents overfitting (memorizing training data). In XGBoost, λ penalizes large leaf weight magnitudes via L2 (ridge) penalty.
